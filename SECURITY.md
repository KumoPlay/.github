# Security Policy

We want KumoPlay to be a safe place to play, for players of every age. Thank you for helping us keep it that way! 💜

## What counts

Please tell us about anything that could put players or their information at risk, for example:

- a way to run code or change content on one of our games or on [kumoplay.github.io](https://kumoplay.github.io)
- a way to see or change another player's data
- a link or page that could trick players (for example a fake login or a harmful redirect)
- anything that could make a game unsafe for children

If you're not sure whether something counts, please report it anyway.

## How to report a problem privately

Please **don't** open a public issue, discussion, or pull request about it. Instead:

1. Go to the repository where you found the problem (for the website, that's [KumoPlay/kumoplay.github.io](https://github.com/KumoPlay/kumoplay.github.io)).
2. Open the **Security** tab and click **Report a vulnerability**. Only you and the KumoPlay team can see what you send.

If you can't find that button, email KumoPlay's developer, [Werayootk](https://github.com/Werayootk), at **[werayoot5800@gmail.com](mailto:werayoot5800@gmail.com)**.

It really helps if you include:

- which game or page is affected
- what the problem is and what someone could do with it
- the steps to see it happen (screenshots are welcome)

## What happens next

We're a small team, so please give us a little time. We'll let you know we got your report, keep you updated while we fix it, and thank you when it's done (unless you'd rather stay anonymous). Please keep the details private until we've had a chance to fix it.

## Supported versions

We only maintain the version of each game and of the website that is live right now. There are no older versions to patch, so please always check against the latest one.
