# KumoPlay `.github`

This repository holds KumoPlay's organization profile and the community files that every KumoPlay repository shares.

🎮 **Looking for the games?** They're all at [kumoplay.github.io](https://kumoplay.github.io).

## What's in here

| File | What it does |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The welcome page shown at [github.com/KumoPlay](https://github.com/KumoPlay) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report bugs, share ideas, and contribute |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | How we treat each other |
| [`SECURITY.md`](SECURITY.md) | How to report a security problem privately |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | The "Bug report" and "Game idea or feedback" forms |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | The short checklist shown when someone opens a pull request |

## Good to know

- These files apply to **every KumoPlay repository that doesn't have its own version**. If a game repository adds its own `CONTRIBUTING.md`, that one is used there instead.
- Issue templates are all-or-nothing: if a repository has its own `.github/ISSUE_TEMPLATE/` folder, none of these templates are used there.
- GitHub only looks for issue and pull request templates inside the `.github/` folder **of this repository**, which is why there's a `.github` folder inside the `.github` repository.
- This repository must stay **public** for the defaults to work.
- Licenses can't be shared this way. Each game repository needs its own `LICENSE` file.
